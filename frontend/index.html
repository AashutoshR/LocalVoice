Run an experiment

Current recipes: configs/research-e19.json (E19, partial freezing) and configs/research-e22.json (E22, Fisher EWC). These commands are for a fresh experiment directory; completed runs are preserved.

.venv\Scripts\python.exe -m localvoice.cli train E19 --config configs/research-e19.json
.venv\Scripts\python.exe -m localvoice.cli evaluate E19

Start with validation results. Freeze experiment choices before unlocking test evaluation.

Dataset readiness

Prepare the dataset

Download the official Spanish parquet exports and convert clips to mono 16 kHz WAV. Original splits are retained.

.venv\Scripts\localvoice prepare
.venv\Scripts\localvoice validate

FLEURS is read speech. Results will not establish performance on spontaneous speech or every Spanish dialect.
